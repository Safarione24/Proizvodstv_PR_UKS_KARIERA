# Сайт УКЦ «Карьера»

Сайт учебно-курсового центра на Django. Включает в себя лицевую часть (расписание, профессии, новости), формы заявок, галерею, отзывы, FAQ и админку для сотрудников.

## 🚀 Как запустить проект (Инструкция для Windows)

Если ты скачал этот проект и хочешь его запустить, делай по шагам:

### 1. Создай виртуальное окружение
Открой терминал (PowerShell) в папке с проектом (там, где лежит файл `manage.py`) и напиши:
```powershell
python -m venv venv

2. Активируй окружение

.\venv\Scripts\Activate.ps1

3. Установи зависимости

pip install -r requirements.txt

4. Подготовь базу данных

python manage.py migrate

5. Создай аккаунт администратора(Введи логин, email можно пропустить, и придумай пароль).

python manage.py createsuperuser

6. Запусти сервер

python manage.py runserver

После этого сайт будет доступен по адресу: http://127.0.0.1:8000/
А админка: http://127.0.0.1:8000/admin/


🛠 Функционал

    Главная страница: Список активных групп, сгруппированный по датам старта. Есть фильтры по категориям и поиск.

    Блок «Скоро экзамен»: Автоматически показывает группы, у которых экзамен в ближайшие 7 дней.

    Заявки на обучение: На странице каждой профессии есть форма «Записаться». Все заявки падают в админку.

    Галерея, Отзывы, FAQ: Выводятся на главной (если добавлены в админке).

    Страница «Документы»: Список необходимых документов для зачисления.

    JSON API: Для фронтенд-разработчиков доступны эндпоинты /api/groups/, /api/professions/, /api/news/.

📂 Структура

    manage.py — главный файл для управления проектом.

    ukc_kariera/ — настройки проекта (settings.py, urls.py).

    core/ — основное приложение:

        models.py — база данных (Профессии, Группы, Новости, Заявки, Фото, Отзывы, FAQ).

        views.py — логика страниц.

        admin.py — настройка админки.

        templates/core/ — HTML-шаблоны.

        static/core/css/ — стили сайта.
